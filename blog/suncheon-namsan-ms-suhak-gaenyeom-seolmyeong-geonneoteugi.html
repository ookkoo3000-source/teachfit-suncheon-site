학습 예시: 개념 한 줄 정리

아래는 개념을 자기 말로 정리하는 방법을 보여 주려고 만든 예시예요.

  • 개념: 일차방정식의 해
  • 내 말로: 식에 넣었을 때 등식이 참이 되게 하는 x의 값
  • 확인: 2x + 1 = 7에서 x = 3을 넣으면 7 = 7 → 해가 맞음
  • 헷갈린 점: 해를 구한 뒤 원래 식에 넣어 확인하는 것을 자주 잊음

'내 말로' 칸을 채우지 못하면 아직 개념이 잡히지 않은 거예요. 그때는 교과서 설명을 한 번 더 읽어요.

예제는 가리고 먼저

교과서 개념 설명 뒤의 예제는 풀이를 가리고 먼저 혼자 풀어 본 뒤 풀이와 비교해요. 풀이를 먼저 읽으면 이해한 것 같지만 혼자서는 다시 풀지 못하는 경우가 많아요.
